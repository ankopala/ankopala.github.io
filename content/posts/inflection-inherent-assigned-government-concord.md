## 1. 6.1.2 固有屈折 vs 指派屈折（Inherent vs. assigned）

**判断标准**：这个屈折信息，是「词本身在词库里就带着的」，还是「词进入句子后、靠句法位置才获得的」？

| | 固有（inherent） | 指派（assigned） |
| --- | --- | --- |
| 信息从哪来 | 词的**心理词库（mental lexicon）** 里就标好了 | 靠词在**句子里的位置/关系**临时获得 |
| 谁决定 | 词本身 / 语义 | 句法 |
| 典型范畴 | 性（gender）、部分数（number） | 格（case） |

### 性（gender）是标准例子

- **名词、代词的性 → 固有**。法语 `fourchette`（叉子）是阴性，词库里就带，与句子无关。
- **形容词、动词反映的性 → 指派**。形容词自己没性，是「借」它修饰的名词的性。

> 一句话：名词「拥有」性（固有），形容词「反映」性（指派）。

### 数（number）：多数自由、少数固有

- **多数情况非固有**：`book → book / books`，单复数是**说话人按语义意图自由选择**，不是句法逼的。
- **例外固有**：`scissors`（剪刀）天生复数（plurale tantum），词库里就标好了。有些语言的动词也只能单/只能复，也算固有数。

### 格（case）：指派屈折的标准例子

> 名词和代词在词库里**没有**格，是**凭借句子里的位置**才获得格的。处在宾语位置的名词，在很多语言里以宾格出现。

### 关键结论：这节收束了 6.1 开头的「张力」

- 作者 6.1 开头说 `inflectional morphology is determined by syntax`；
- 但**格（assigned）才真正被句法决定**，**性和部分数（inherent）不受句法左右**；
- 所以那句强断言，严格讲**只对「指派」这一半成立**。

```
屈折信息的来源
├── 固有 inherent（词库里带着）→ 不靠句法
└── 指派 assigned（句法给的）→ 需要解释「怎么指派」
      ├── 一致 concord / agreement
      └── 管辖 government
```

## 2. 6.1.3 管辖 vs 一致（Government vs. concord）

**回答的问题**：当一个词的屈折信息是「别人给的」（指派），这个「给」是怎么给的？只有两种。

### 一致（concord / agreement）——「照抄别人的特征」

> 句子里一个成分，承接了另一个成分的形态句法特征。

- 罗曼语/德语的**名词-形容词一致**：形容词的性数照抄名词。

```
法语 une petite fille（一个小女孩）
      阴.单  阴.单   阴.单
      ↑      ↑       ↑   这三个「阴、单」都是照抄 fille，不是各自独立决定
```

- Kujamaat Jóola 语：修饰名词的形容词、动词都要和名词的性/类一致。

**本质**：一个成分**被动复制**另一个成分已有的特征。

### 管辖（government）——「强制规定别人的形式」

> 一个词 **规定（dictate）** 另一个词的形式。

- 标准例子：动词/介词给宾语指派格。
- 关键：名词用宾格**不能说是在跟动词「一致」**，因为**动词本身没有格**，没法「照抄」一个不存在的东西。

```
德语 Wir sahen den jungen Piloten（我们看见这位年轻飞行员）
         ↑ 动词 sehen 要求直接宾语用宾格 → 管辖
```

德语与格：同样是「动词后宾语」这个位置，不同动词要求不同的格：

```
Ich sehe  den Mann.   （我看见这个男人）—— den Mann 是宾格
Ich helfe dem Mann.   （我帮助这个男人）—— dem Mann 是与格
```

关键：`Mann` 在两个句子里**都处在动词后的宾语位置**，却一个是宾格、一个是与格。所以「位置」本身决定不了格——**是管辖它的动词决定的**：`sehen` 管辖宾格，`helfen` 管辖与格。

> 位置决定「谁来管你」，管辖决定「把你变成什么格」——两层分工，不是互相替代。

### 核心区别：一致是「抄」，管辖是「令」

| | 一致 concord | 管辖 government |
| --- | --- | --- |
| 关系 | **照抄**另一个成分的特征 | **强制规定**另一个成分的形式 |
| 方向感 | 水平：特征在成分间复制 | 垂直：一个词「要求」另一个词 |
| 前提 | 被抄的那个成分**自己得有**这个特征 | 管辖者**自己可以没有**这个特征 |
| 典型 | 名词 → 形容词的性数一致 | 动词/介词 → 宾语指派格 |

> 记忆：形容词「**学着名词的样子**」变；动词「**命令名词**」变。

### 反直觉陷阱：特征 ≠ 机制

同一个句子、同一个「宾格」，来源可能不同：

```
动词 sehen ──管辖──▶ 名词 Piloten（宾格）
                        │
                        └──一致──▶ 冠词 den、形容词 jungen（照抄宾格）
```

> 结论：**屈折的机制（一致 vs 管辖）独立于屈折特征本身（格/性/数）。** 不能给「格」贴固定标签说它是「管辖特征」——格既可经一致、也可经管辖获得。

## 3. 补充：英语里的 government 与格残迹（答疑延伸）

### 英语的格系统已严重退化

```
英语的格
├── 主格 vs 宾格   —— 只活在代词上：I/me, he/him, she/her, we/us, they/them, who/whom
├── 属格          —— -'s 和 of
├── 与格          —— 无独立词形，靠介词 to + 双宾结构「代偿」
└── 工具格等      —— 已完全消失
```

### 英语里最干净的 government 例子

```
He saw me.        （动词 saw 要求宾格 me，不是 *saw I）
He gave it to me. （介词 to 要求宾格 me，不是 *to I）
```

- 介词 `to` / `for` 要求其后代词用宾格 → 这就是 government。
- 英语的「与格」靠 `to` + 双宾结构表达：

```
I gave Mary a book.    =  I gave a book to Mary.
      ↑ Mary 占据的正是「与格/间接宾语」的位置
```

### 为什么中文母语者会有盲区

1. 中文靠**语序 + 虚词**（把字句、给字句），从无「词形随格而变」；
2. 英语格已**萎缩到只剩代词那几对**，母语者自己都在丢（`whom` 快没人用了）。

两种语言恰好都把格系统磨平了，所以「与格」「格指派」对中英母语者是抽象的、课本里的东西，而非母语里能摸到的。
